# Privacy Policy

**Effective Date:** August 23, 2026  
**Last Updated:** August 23, 2026

This Privacy Policy explains how **StarKid**, developed by **StarKid Marshal**, may collect, process, use, and protect information when you use the StarKid Discord bot.

By using StarKid, you acknowledge the practices described in this Privacy Policy.

## 1. Information We May Process

Depending on which features of StarKid you use, the bot may process certain information available through Discord.

This may include:

### Discord Account Information

StarKid may receive basic information associated with your Discord account, such as:

- Discord User ID
- Username
- Display name
- Server/guild membership
- Roles and permissions relevant to bot commands

This information may be required for the bot to correctly identify users and provide features.

### Server Information

When StarKid is added to a Discord server, it may process information such as:

- Server/Guild ID
- Server name
- Channel IDs
- Role IDs
- Server configuration
- Permissions required for bot functionality

This information may be used to provide moderation, administration, reaction-role, music, and other server features.

### Messages and AI Conversations

When you interact with StarKid's **AI Chat Buddy**, the messages or prompts you send may be processed by the AI system in order to generate a response.

For example, if you send:

> "Hey StarKid, what should I play tonight?"

the content of that message may need to be processed by the AI service in order to generate a response.

Please avoid providing passwords, payment information, private credentials, or other highly sensitive information to the AI Chat Buddy.

### Bot Commands

StarKid may process information about commands used with the bot, including:

- The command used
- The Discord user who used it
- The server where it was used
- Information necessary to execute the command
- Relevant command options or parameters

This may be necessary for the bot to perform requested actions and maintain functionality.

## 2. Moderation Information

When StarKid's moderation features are used, the bot may process information necessary to perform or record moderation actions.

Depending on the server's configuration, this may include:

- User IDs
- Moderator IDs
- Moderation actions
- Reasons provided for moderation actions
- Relevant timestamps
- Server and channel information

Examples of moderation actions include warnings, kicks, bans, timeouts, message deletion, role changes, and other administrative actions.

Server administrators are responsible for configuring and using these features appropriately.

## 3. Music Features

When you use StarKid's music features, the bot may process information necessary to provide music playback.

This may include:

- User ID
- Server and voice-channel information
- Music commands
- Search queries
- Song or media URLs
- Queue information

StarKid may rely on third-party services to provide certain music functionality.

## 4. How Information Is Used

Information processed by StarKid may be used to:

- Provide and operate the bot.
- Respond to AI conversations.
- Execute commands.
- Perform moderation actions.
- Provide music functionality.
- Manage server configurations.
- Diagnose technical problems.
- Improve reliability and functionality.
- Prevent abuse, exploitation, or unauthorized use.
- Maintain the security of the bot and its infrastructure.

StarKid does not intentionally use information for purposes unrelated to providing, maintaining, securing, or improving its services unless otherwise stated.

## 5. Data Storage and Retention

Not all information processed by StarKid is necessarily stored permanently.

Some information may only be processed temporarily while a command or feature is being executed.

Where information is stored, the retention period may depend on the purpose for which it was collected and the technical requirements of the relevant feature.

For example, server configuration may need to be retained so that StarKid can remember settings after restarting.

Moderation or logging information may also be retained when those features are configured by a server administrator.

We aim to retain information only for as long as reasonably necessary for the relevant purpose.
